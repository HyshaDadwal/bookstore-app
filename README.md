# 📚 Online Bookstore Application

A full-stack Online Bookstore Application built using **React.js**, **Spring Boot**, **JWT Authentication**, and **PostgreSQL (NeonDB)**.

The platform allows users to browse books, manage carts, place orders, and provides admin functionality for managing books and users.

# ✨ Features

## 👤 User Features

- User Registration & Login
- JWT Authentication
- Browse Books

- View Orders
- Wishlist Support
- Responsive UI

---

- Admin Login
- Add Books
- Delete Books
- Manage Orders
- Manage Users
- Protected Admin Routes
